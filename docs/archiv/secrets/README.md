# Archiv: Secrets und Easter Eggs (MS60, entfernt in MS72)

Auf Wunsch des Auftraggebers vorerst entfernt (man bemerkte sie kaum, Meldungen waren unklar). Hier liegt alles für einen späteren, sauberen Neueinbau:
- `secrets.json` – 10 Secrets mit Steam-Erfolgs-IDs
- `secret_objects.json` – Objekt-Definitionen (rissige Wände, Gummienten, goldener Haufen, Toilette, Kaltholz-Kühlschrank, Entwicklerwand)
- `secret_system.gd.txt`, `secrets_view.gd.txt`, `test_secrets.gd.txt` – Code und Tests
- `gen_map_secrets.txt` – Platzierung im Kartengenerator
- `toilet.svg` – Grafik
