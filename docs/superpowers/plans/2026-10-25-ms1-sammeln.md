# MS1 Sammeln – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rusty sammelt auf der Tutorial-Map alle drei Rohstoffe mit Sauger und Hammer ein, das Inventar füllt sich sichtbar in der Hotbar, Wracks zerfallen in lose Items, Haufen wachsen nach, Rusty kommentiert.

**Architecture:** Alle Spielregeln liegen in `src/sim/` (RefCounted, Integer-Positionen in Pixeln, Ticks statt Sekunden). Der Player-Node schreibt pro Physik-Frame nur Eingaben in `PlayerState` (Position, Zielrichtung, Trigger gehalten/gedrückt); die Sim entscheidet im Tick, was passiert, und meldet Änderungen über Signale von `SimWorld`. Views (`src/world/`) hören auf die Signale und spiegeln den Zustand. Daten kommen aus `data/*.json`, Texte aus `locale/strings.csv`.

**Tech Stack:** Godot 4.7.2, GDScript, JSON, CSV-Übersetzungen, SVG-Platzhalter.

**Spec:** `docs/01_GDD.md` Kap. 4, 5.1, 10, 11, 12; `docs/02_ARCHITECTURE.md` Kap. 3, 4.5, 4.10; `docs/03_ROADMAP.md` MS1.

## Global Constraints

- Sim-Positionen sind `Vector2i` in Pixeln, Dauern in Ticks (20/s). Nur die Kegelprüfung des Saugers nutzt Floats (Winkel), was auf demselben Gerät deterministisch bleibt.
- Inventar 6 Slots × 20 Stück. Sauger: Kegel 90°, Reichweite 2,5 Kacheln (160 px), 1 Item / 5 Ticks. Hammer: Reichweite 1 Kachel (64 px) vor Rusty, 1 Schlag / 10 Ticks, 1 Item pro Schlag.
- Haufen: max. 10, +1 alle 600 Ticks (30 s). Wracks: 20–40 Items, kein Nachwachsen, verschwinden bei 0.
- Schriftgrößen ≥ 22 px; Hotbar-Slots 72 px; Sprechblase max. 60 Zeichen, eine Zeile.
- Alle sichtbaren Strings über `tr()`; `locale/strings.csv` mit Spalten `keys,de,en`.

- `class_name LooseItem` — `id: int`, `item_id: String`, `pos: Vector2i`.

### Task 3: PlayerState und Welt-Regeln (Sim) mit Tests

**Files:** Create `src/sim/player_state.gd`; Modify `src/sim/world.gd`; Create `tests/test_world_collect.gd`

**Interfaces:**
- `class_name PlayerState` — `pos: Vector2i`, `aim: Vector2` (normalisiert, Eingabe), `suck_held: bool`, `hammer_pressed: bool` (wird von Sim nach Verbrauch auf false gesetzt), `inventory: Inventory` (6×20), `suck_cooldown: int`, `hammer_cooldown: int`, Konstanten `SUCK_RANGE_PX := 160`, `SUCK_HALF_ANGLE_RAD := PI / 4`, `SUCK_INTERVAL := 5`, `HAMMER_RANGE_PX := 64`, `HAMMER_INTERVAL := 10`.
- `SimWorld` erweitert: `width_tiles`, `height_tiles`, `player: PlayerState`, `rng: SimRng`, `nodes: Dictionary` (id → ResourceNode), `loose: Dictionary` (id → LooseItem), `add_node(node)`, `add_loose(item_id, pos) -> LooseItem`. Signale: `node_added(node)`, `node_changed(node)`, `node_removed(id)`, `loose_added(item)`, `loose_removed(id)`, `item_collected(item_id, from_pos: Vector2i)`, `inventory_full()`, `wreck_hit(node)`, `wreck_destroyed(id)`.
- Tick-Regeln: (1) alle Nodes ticken, bei Änderung `node_changed`. (2) Saugen: wenn `suck_held` und `suck_cooldown == 0`: Ziel = nächstes loses Item oder Haufen (nicht Wrack) im Kegel (Abstand ≤ 160, Winkel zu `aim` ≤ 45°) mit amount > 0; lose Items haben Vorrang; wenn Inventar `can_add(item)`: entnehmen, `inventory.add`, `item_collected`, Cooldown 5; sonst `inventory_full` (einmal, bis wieder Platz). (3) Hammer: wenn `hammer_pressed` und `hammer_cooldown == 0`: Ziel = Wrack, dessen Mittelpunkt ≤ 64 px von `pos + aim × 48` entfernt ist; `take_one` → `add_loose` an Zufallsposition im Umkreis 40 px (SimRng) um das Wrack, `wreck_hit`; bei `is_depleted` entfernen + `wreck_destroyed`; Cooldown 10; `hammer_pressed = false` immer am Tickende. (4) Cooldowns herunterzählen.

- [x] Tests: Haufen im Kegel wird gesaugt, Inventar +1, Haufen −1; Haufen außerhalb Kegel (hinter Rusty) nicht; Cooldown: 5 Ticks gehalten = 1 Item, 10 Ticks = 2; volles Inventar → `inventory_full` einmal, Haufen unverändert; Hammer auf Wrack erzeugt loses Item, Wrack −1; loses Item wird vor Haufen bevorzugt gesaugt; Wrack bei 0 entfernt + Signal; Hammer außerhalb Reichweite tut nichts.
- [x] Implementierung, Tests grün, Commit `ms1: Saugen und Hämmern in der Simulation`.
